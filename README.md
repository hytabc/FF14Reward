# 星海回响 · 艾欧泽亚人生重开录

以《最终幻想14》世界与游戏生态为灵感的非官方同人人生重开游戏。玩家从新生庆典醒来，在八个篇章中做出选择，培养意志、以太、羁绊、名望与暗影，最终在星海尽头回答世界。

## 玩法内容

- **42 个可收集结局**：包含 6 个即时歧路结局、35 个最终结局与真结局。
- **7 条最终道路**：熔尽光、拒绝神、远航、留下、王座、终末、重启。
- **8 个主线篇章**：从沙斯塔夏溶洞、伊弗利特讨伐，到伊修加德、第一世界、加雷马、萨雷安与图莱尤拉。
- **10 种职业、5 个出生地、7 位守护神**，组合出不同的初始属性与被动倾向。
- **拂晓成员关系系统**：塔塔露、雅·修特拉、埃斯蒂尼安、古·拉哈·提亚、阿莉塞、埃伦维尔、乌克·拉玛特、可露儿。
- **MMO 生态陪伴面板**：任务搜索器、招募板、市场行情与世界频道会随章节变化。
- **周目继承**：结局解锁为星海图鉴，并累积星砂，为下一次人生提供属性加成。
- 游戏进度与结局图鉴使用 `localStorage` 自动保存。

## 开发运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

若本机已有依赖且只想预览构建产物：

```bash
npm run build
npm run preview:dist
```

默认预览地址为 `http://127.0.0.1:5173`。

## 技术栈

- React 19
- TypeScript
- Vite
- 原生 CSS 视觉系统与 SVG 图标
- 无后端、无外部图片、无运行时网络依赖

## GitHub Pages

仓库已包含 `.github/workflows/deploy.yml`。推送到 `main` 后，GitHub Actions 会自动构建并部署到：

`https://<GitHub用户名>.github.io/FF14Reward/`

首次使用时，请在仓库的 **Settings → Pages → Build and deployment** 中将 Source 设为 **GitHub Actions**。
